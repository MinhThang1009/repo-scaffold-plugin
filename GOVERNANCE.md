# Governance

## Maintainer

`repo-scaffold` is currently maintained by Minh Thang. The maintainer sets the
project direction, reviews contributions, manages releases, and applies the
security and conduct policies.

## Contributors

Anyone may propose code, documentation, tests, templates, workflow updates, or
review feedback by following [CONTRIBUTING.md](CONTRIBUTING.md). Contributions
do not grant commit, release, or moderation authority.

## Decisions

Routine changes are decided through technical review of focused pull requests.
Changes to security boundaries, permissions, public behavior, compatibility,
release integrity, or repository policy require explicit maintainer approval
and evidence from current authoritative documentation.

Security reports and conduct incidents are handled privately according to
[SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Maintainer succession

Sustained, high-quality contribution may lead to an invitation to help maintain
the project. Any change in maintainership must be documented publicly before the
new maintainer receives release, repository-administration, or security access.
