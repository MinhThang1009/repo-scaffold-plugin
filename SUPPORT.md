# Support

## Usage help

For a locally shared installation, contact the person or workspace that supplied
the plugin. Include:

- the plugin version;
- the Codex environment and operating system;
- the target repository stack;
- the scaffold options requested;
- the exact non-sensitive error output.

After this repository is published with GitHub Issues enabled, use its issue
template chooser for reproducible bugs and feature requests.

## Security

Do not report vulnerabilities through public issues. Follow the
[Security Policy](SECURITY.md).

## Conduct

For community conduct concerns, follow the private reporting guidance in the
[Code of Conduct](CODE_OF_CONDUCT.md).

Never include tokens, credentials, private repository data, or other sensitive
information in public reports.
