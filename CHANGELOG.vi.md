## [Chưa phát hành]

### Đã thêm

* Bổ sung markdownlint đã pin và GitHub Actions kiểm tra liên kết theo lịch,
  cùng validator xác định nội dung tài liệu đã render cho scaffold hiện tại và
  tương lai.
* Bổ sung attestation SLSA có chữ ký cho provenance build của release, tách khỏi
  build dự án bằng quyền workflow tái sử dụng tối thiểu.
* Bổ sung CI đa nền tảng, dependency review và cấu hình Dependabot.
* Bổ sung Commitlint, gắn nhãn pull request và tự động hóa issue/PR cũ.
* Bổ sung thiết lập nâng cao CodeQL do repository quản lý cho Python, kèm
  workflow asset có thể tái sử dụng và render theo stack.
* Bổ sung cấu hình Release Please để tự động hóa tạo phiên bản và release.
* Bổ sung lint workflow bằng ShellCheck và kiểm tra hợp đồng repository có tính
  xác định.
* Bổ sung tự động hóa GitHub Release theo tag cho archive plugin có phiên bản.
* Tăng cường ownership, editor, ignore và tài liệu cộng đồng của repository.

### Đã thay đổi

* Tập trung cài đặt khởi động CI luân phiên và pin release đã review cho công cụ
  độc lập trong một chính sách máy đọc được, kèm phát hiện drift upstream theo
  lịch.
* Căn giữa header và badge README, đánh số outline và bổ sung mục lục thủ công
  đầy đủ.
* Nêu rõ quy trình scaffold về phát hiện ngôn ngữ tài liệu và quy ước Markdown/
  template.
* Bổ sung lựa chọn ngôn ngữ tiếng Anh/tiếng Việt theo từng dự án có tính xác
  định và áp dụng nhất quán ngôn ngữ đã chọn cho nội dung cộng đồng và release.
* Cập nhật xác minh issue form theo schema hiện hành của GitHub, gồm trường tải
  tệp lên và yêu cầu nhận dạng đuôi `.yml` đã tài liệu hóa.
* Làm mới GitHub Actions được đóng gói theo các release hiện đã xác minh, dùng
  commit pin bất biến.
* Mở rộng xác minh repository để thực thi ranh giới attestation release, quyền
  caller, phạm vi artifact và cổng publish.
* Thay bộ điều phối tag thủ công của repository bằng Release Please, đồng thời
  giữ nguyên release engine tái sử dụng đã được cô lập.
