# Governance

## Roles

- **Maintainers**: review and merge contributions and set project direction (see [CODEOWNERS]({{REPO_SCAFFOLD_CODEOWNERS_LINK}})).
- **Contributors**: anyone who contributes code, documentation, review, testing, or project feedback.

## Decisions

Day-to-day changes are decided by maintainer review on pull requests. Significant or
breaking changes are agreed with maintainers through an enabled project channel before implementation.

## Becoming a maintainer

Sustained, high-quality contributions may lead to an invitation from the existing maintainers.
